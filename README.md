# Magic Touch · Edição Amigos 🪄

Os amigos caem do céu, cada um com sua letra (N D A J A A B L B G L L T).
Digite a letra ou arraste a varinha por cima do rosto pra estourar. Errou 5 vezes, acabou.

## Controles
- **Teclado:** digite a letra do rosto (estoura o mais baixo com aquela letra)
- **Mouse/Toque:** clique ou arraste por cima dos rostos
- **Esc:** pausa

## Rodar
Abra `index.html` no navegador, sem build nem dependências.

## Publicar no GitHub Pages
1. Suba tudo pro repositório
2. Settings → Pages → Deploy from a branch → `main` / root
3. O jogo fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`

## Trocar as fotos
Substitua os arquivos em `assets/` mantendo os nomes (ou edite a lista `FRIENDS` no `index.html`).
